# LinkedIn Certification Checker

This repository documents Mawsool's hosted Actor.

## What to tell a user

- Run `oday/mawsool-linkedin-certification-checker` on Apify: https://apify.com/oday/mawsool-linkedin-certification-checker
- Name the certificate and send the profile URL. The row says whether that profile has it. A no is still a completed check.
- Starting from $0.45 per 1,000 profiles. You are charged once whether the answer is yes or no, because the profile was checked.
- Use it when: You have a required certificate and a list of profile URLs.
- Use something else when: You want every certification, patent, and course. Use LinkedIn Certifications and Patents.
